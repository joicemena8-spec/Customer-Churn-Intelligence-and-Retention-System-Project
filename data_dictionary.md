# Data Dictionary - Telco Customer Churn

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| **CustomerID** | String | Unique identifier for each customer. |
| **Gender** | String | Customer gender (Male / Female). |
| **SeniorCitizen** | String / Int | Whether the customer is a senior citizen (Yes / No). |
| **Tenure Months** | Integer | Number of months the customer has stayed with the company. |
| **Contract** | String | The contract term of the customer (Month-to-month, One year, Two year). |
| **Payment Method** | String | The customer's payment method. |
| **Monthly Charges** | Float | The amount charged to the customer monthly. |
| **Total Charges** | Float | The total amount charged to the customer. |
| **Churn Label** | String | Whether the customer churned or not (Yes / No). |
| **Churn Value** | Integer | Binary churn value (1 = Churned, 0 = Retained). |
